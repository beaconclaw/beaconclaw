# The systems BeaconClaw recognises from the names of credentials.
#
# One system per line: the name people call it, a tab or " = ", then the
# prefixes a credential name can begin with, separated by spaces. Names are
# compared in upper case. A prefix ending in "_" matches a whole word: "GH_"
# matches GH_TOKEN and not GHOST_API_KEY. The first line that matches wins, so
# put a longer prefix above a shorter one that would also match.
#
# To add a system, add a line and send a pull request. Nothing here is a
# secret: these are names a runtime's skills declare in public.
